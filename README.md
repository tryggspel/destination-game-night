# Destination Game Night

Spelbar pilotdemo för O’Learys Karlstad med tre bildledtrådar och sju frågor i geografi, sport, allmänbildning och aktualiteter. Välj **Starta TV-demon** för en automatisk visning eller **Spela med fyra lag** för att styra spelet från kontrollrummet.

Sidan kör spelet lokalt i webbläsaren. Grafik, ljud och filmer ingår i `index.html`.

[Öppna demon](https://tryggspel.github.io/destination-game-night/)
