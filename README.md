# Destination Game Night

Spelbar pilotdemo för O’Learys Karlstad med tre bildledtrådar och sju frågor, varav fyra om matcher i Champions League, SHL, Allsvenskan och NHL. Välj **Starta TV-demon** för en automatisk visning eller **Spela med fyra lag** för att styra spelet från kontrollrummet.

Producentläget stödjer en eller två kameror och exporterar hela programmet samt en reel per lag. Sidan spelar in och klipper lokalt i webbläsaren. Grafik, ljud och filmer ingår i `index.html`. Publikljudet kommer från [Riancodgamer på Freesound](https://freesound.org/people/Riancodgamer/sounds/414985/) under CC0. Logotypfilen kommer från [O’Learys Groups pressarkiv](https://www.mynewsdesk.com/se/olearysgroup/images/olearys-logo-cmyk-2758051).
